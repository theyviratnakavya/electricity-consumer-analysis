# Electricity Consumer Analysis

A Streamlit-based data analysis and visualization project using an electricity consumer dataset.

## Features

* Loads electricity consumer data
* Displays dataset columns and shape
* Performs basic data analysis
* Visualizes consumer types
* Provides interactive charts using Streamlit

## Technologies Used

* Python
* Pandas
* Matplotlib
* Streamlit

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Dataset

The project uses an ARFF electricity consumer dataset containing consumer-related attributes and service information.
